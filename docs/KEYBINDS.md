# اختصارات لوحة المفاتيح

الاختصارات المدعومة في Mahdi-Editor عند توصيل لوحة مفاتيح خارجية. يمكن تغييرها من
**الإعدادات ‹ اختصارات لوحة المفاتيح**.

## الملفات

| الاختصار | الإجراء |
|---|---|
| <kbd>CTRL</kbd>+<kbd>S</kbd> | حفظ الملف الحالي |

## التحرير

| الاختصار | الإجراء |
|---|---|
| <kbd>CTRL</kbd>+<kbd>X</kbd> | قص النص المحدد |
| <kbd>CTRL</kbd>+<kbd>C</kbd> | نسخ النص المحدد |
| <kbd>CTRL</kbd>+<kbd>V</kbd> | لصق |
| <kbd>CTRL</kbd>+<kbd>A</kbd> | تحديد كل النص |
| <kbd>CTRL</kbd>+<kbd>Z</kbd> | تراجع |
| <kbd>CTRL</kbd>+<kbd>Y</kbd> | إعادة |
| <kbd>CTRL</kbd>+<kbd>D</kbd> | تكرار السطر الحالي |
| <kbd>CTRL</kbd>+<kbd>W</kbd> | تحديد الكلمة الحالية |

## التنقل والبحث

| الاختصار | الإجراء |
|---|---|
| <kbd>CTRL</kbd>+<kbd>F</kbd> | بحث داخل المستند |
| <kbd>CTRL</kbd>+<kbd>H</kbd> | بحث واستبدال |

## ملاحظات

- اختصارات لوحة المفاتيح الخارجية تعمل مع المحرر؛ راجع شاشة الاختصارات في التطبيق للقائمة الكاملة
  والقابلة للتخصيص.
- جميع الاختصارات تعمل بغض النظر عن اتجاه واجهة التطبيق (RTL أو LTR).
