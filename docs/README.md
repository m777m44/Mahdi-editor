## أسئلة سريعة

**كيف أُغيّر اللغة؟**
الإعدادات ‹ اللغة ‹ اختيار `ar`. اللغة الافتراضية في هذه النسخة هي العربية.

**كيف أفتح تصفح الإضافات؟**
الإعدادات ‹ تصفح الإضافات (أو من الشاشة الرئيسية). فيه أربعة تبويبات: الإضافات، الثيمات،
حزم الأيقونات، خوادم ومشغّلات.

**كيف أثبّت ثيمًا جاهزًا؟**
الإعدادات ‹ تصفح الإضافات ‹ الثيمات، ثم اختر أي ثيم من الستة عشر — يُثبَّت ويُطبَّق فورًا.

**كيف أُثبّت مفسّر لغة؟**
الإعدادات ‹ تصفح الإضافات ‹ خوادم ومشغّلات ‹ زرّ التثبيت بجانب اللغة. بعد اكتمال التثبيت
تظهر شارة «مثبت» وتبقى محفوظة بعد إعادة التشغيل.

**هل توجد إعلانات أو تتبّع؟**
لا. التطبيق لا يجمع بيانات. مساعد الذكاء الاصطناعي وخدمات اللغة تعمل فقط إذا فعّلتها ووفّرت
مفتاح API خاصًا بك.

**أين أجد السجلات؟**
الإعدادات ‹ خيارات التصحيح ‹ تمكين Logcat، ثم عرض السجلات.
