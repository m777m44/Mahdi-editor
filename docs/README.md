## أسئلة سريعة

**كيف أُغيّر اللغة؟**
الإعدادات ‹ اللغة ‹ اختيار `ar`. اللغة الافتراضية في هذه النسخة هي العربية.

**لماذا لا يعمل المتجر؟**
المتجر الإلكتروني معطّل في هذه النسخة لأنه كان مرتبطًا بخوادم المشروع الأصلي. ثبّت الإضافات
والثيمات من ملف محلي عبر «التثبيت من التخزين».

**كيف أثبّت ثيمًا عربيًا جاهزًا؟**
الثيمات السبعة مدمجة في التطبيق: الإعدادات ‹ الثيمات.

**هل توجد إعلانات أو تتبّع؟**
لا. التطبيق لا يجمع بيانات. مساعد الذكاء الاصطناعي وخدمات اللغة تعمل فقط إذا فعّلتها ووفّرت
مفتاح API خاصًا بك.

**أين أجد السجلات؟**
الإعدادات ‹ خيارات التصحيح ‹ تمكين Logcat، ثم عرض السجلات.
