## أسئلة سريعة

**كيف أُغيّر اللغة؟**
الإعدادات ‹ اللغة ‹ اختيار `ar`. اللغة الافتراضية في هذه النسخة هي العربية.

**أين أجد كل إعدادات اللغة؟**
الإعدادات ‹ اللغات. فيه أربعة تبويبات: لغة الواجهة، لغات البرمجة، المشغلات، خوادم اللغة.

**كيف أثبّت ثيمًا جاهزًا؟**
الإعدادات ‹ الثيمات، ثم اختر أي ثيم — يُثبَّت ويُطبَّق فورًا.

**كيف أُثبّت مفسّر لغة؟**
الإعدادات ‹ اللغات ‹ المشغلات ‹ زرّ التثبيت بجانب اللغة. بعد اكتمال التثبيت تظهر شارة
«مثبت» وتبقى محفوظة بعد إعادة التشغيل.

**هل توجد إعلانات أو تتبّع؟**
لا. التطبيق لا يجمع بيانات. مساعد الذكاء الاصطناعي وخدمات اللغة تعمل فقط إذا فعّلتها ووفّرت
مفتاح API خاصًا بك.

**أين أجد السجلات؟**
الإعدادات ‹ خيارات التصحيح ‹ تمكين Logcat، ثم عرض السجلات.
