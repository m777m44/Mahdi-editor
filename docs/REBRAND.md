# Mahdi-Editor — هوية المشروع ومسار التطوّر

## الأساس

**Mahdi-Editor** محرّر نصوص وبيئة تشغيل أندرويد كاملة، بُني وأُعيدت هندسته ليكون:

- واجهة عربية بالكامل مع دعم RTL كامل، وواجهة إنجليزية كاملة لمن يفضّلها.
- محرّرًا + طرفية Ubuntu مدمجة + مشغّل ملفات لأكثر من 49 لغة، بلا أي خطوات تثبيت يدوية.
- خفيفًا ومنظّمًا: ثيمات أربعة فقط، بلا متجر خارجي، بلا تتبّع، بلا حسابات.
