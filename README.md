# Mahdi-Editor

<div align="center">

**محرر نصوص وأكواد متقدم لنظام أندرويد — بالعربية بالكامل 🇮🇶**

</div>

Mahdi-Editor محرر أكواد مفتوح المصدر لنظام أندرويد، مبني على محرّك تحرير احترافي، بواجهة عربية كاملة
ودعم أصيل للاتجاه من اليمين إلى اليسار. يوفّر تلوين الأكواد، ودعم LSP، وطرفية Linux مدمجة، ومدير
مشاريع، ونظام ثيمات وإضافات — كل ذلك دون إعلانات ودون تتبّع.

## المزايا

| الميزة | الوصف |
|---|---|
| واجهة عربية 100% | جميع النصوص والقوائم والرسائل معرّبة، ولا تعتمد أي شاشة على النص الإنجليزي |
| دعم RTL كامل | الواجهة تنقلب تلقائيًا عند اختيار العربية (`supportsRtl="true"`) |
| تلوين الأكواد | قواعد TextMate لعشرات اللغات، وتلوين تلقائي حسب الامتداد |
| دعم LSP | إكمال الشيفرة، تشخيص الأخطاء، التنسيق، الانتقال إلى التعريف والمراجع، وإعادة تسمية الرموز |
| طرفية مدمجة | Ubuntu عبر PRoot مع مشغّلات سكربتات ومدير حزم |
| مدير مشاريع | درج ملفات، بحث داخل المشروع، فهرسة، وتبويبات مرتبطة بالمشروع |
| ثيمات | ثيمان مدمجان + **7 ثيمات عربية جديدة** + دعم الثيمات الخارجية |
| ثيمات ديناميكية | Material You على أندرويد 12+، ووضع AMOLED أسود كامل |
| نمط ليلي تلقائي | حسب النظام أو **حسب الوقت** (ليلًا/نهارًا) |
| إضافات | نظام إضافات قابل للتوسّع + تثبيت الحزم من التخزين المحلي |
| بدون إعلانات | لا إعلانات، ولا جمع بيانات، ولا تتبّع |
| مساعد ذكي اختياري | يعمل بمفتاح API الخاص بك فقط، ومُعطّل افتراضيًا |

## البناء من المصدر

### المتطلبات

- JDK 21
- Android SDK مع `compileSdk 37` و`targetSdk 37` (أو أحدث)
- Android NDK + CMake (لبناء وحدات الطرفية الأصلية)
- Git

### الخطوات

```bash
git clone https://github.com/m777m44/Mahdi-editor.git
cd Mahdi-editor

# نسخة تجريبية
./gradlew assembleCommunityDebug

# نسخة الإصدار
./gradlew assembleCommunityRelease
```

الملفات الناتجة:

```
app/build/outputs/apk/community/debug/app-community-debug.apk
app/build/outputs/apk/community/release/app-community-release.apk
```

### التوقيع

- **بناء تجريبي/إصدار دون إعداد:** يتم توقيع نسخة الإصدار تلقائيًا بمفتاح الاختبار المرفق
  (`app/testkey.keystore`) حتى تعمل الحزمة على جهازك مباشرة.
- **بناء للنشر:** أنشئ ملف `signing.properties` في جذر المستودع (انظر
  [`signing.properties.example`](signing.properties.example)) ثم:

```bash
keytool -genkey -v -keystore mahdi-editor.jks -keyalg RSA -keysize 2048 -validity 10000 -alias mahdi
```

تفاصيل كاملة في [docs/BUILDING.md](docs/BUILDING.md).

## الثيمات العربية

سبعة ثيمات مضافة في هذه النسخة، كل ثيم بوضعين فاتح وداكن:

| الثيم | الوصف |
|---|---|
| **مهدي الداكن** | ثيم داكن بألوان ذهبية هادئة |
| **مهدي الفاتح** | ثيم فاتح كريمي بلمسات بنّية |
| **ليل عربي** | ليليّ بألوان تراثية (ذهبي وفيروزي وبنفسجي) |
| **بغداد** | مستوحى من العصر العباسي: ذهب ونحاس وفيروز |
| **صحراء** | رمال وكثبان وألوان نخيل |
| **دجلة** | أزرق نهر دجلة |
| **الفرات** | أخضر نهر الفرات |

تُختار من **الإعدادات ‹ الثيمات**، ويعمل كل ثيم مع الوضع الفاتح والداكن وAMOLED.

## اللغة والاتجاه

- التطبيق **عربي بالكامل**: مجلد الموارد الافتراضي `values/` عربي، والمجلد `values-ar/` نسخة مطابقة،
  ولا توجد أي ترجمة أخرى في التطبيق. يظهر بالعربية على أي جهاز مهما كانت لغة نظامه.
- اللغة الافتراضية `ar` وتُطبّق قبل بناء الواجهة، وشاشة **الإعدادات ‹ اللغة** تعرض العربية وحدها.
- تُضبط اتجاهات الواجهة تلقائيًا (RTL)، مع مراعاة الأيقونات والدرج وشريط الأدوات.
- الملفات النصية تبقى باتجاه LTR داخل المحرر — الاتجاه العربي يخصّ واجهة التطبيق فقط.
