# Mahdi-Editor

<div align="center">

**محرر نصوص وأكواد متقدم لنظام أندرويد — بالعربية بالكامل 🇮🇶**

</div>

Mahdi-Editor محرر أكواد مفتوح المصدر لنظام أندرويد، مبني على محرّك تحرير احترافي، بواجهة عربية كاملة
ودعم أصيل للاتجاه من اليمين إلى اليسار. يوفّر تلوين الأكواد، ودعم LSP، وطرفية Linux مدمجة، ومدير
مشاريع، ونظام ثيمات وإضافات — كل ذلك دون إعلانات ودون تتبّع.

## المزايا

| الميزة | الوصف |
|---|---|
| واجهة عربية 100% | جميع النصوص والقوائم والرسائل معرّبة، ولا تعتمد أي شاشة على النص الإنجليزي |
| دعم RTL كامل | الواجهة تنقلب تلقائيًا عند اختيار العربية (`supportsRtl="true"`) |
| تلوين الأكواد | قواعد TextMate لعشرات اللغات، وتلوين تلقائي حسب الامتداد |
| دعم LSP | إكمال الشيفرة، تشخيص الأخطاء، التنسيق، الانتقال إلى التعريف والمراجع، وإعادة تسمية الرموز |
| طرفية مدمجة | Ubuntu عبر PRoot مع مشغّلات سكربتات ومدير حزم |
| مدير مشاريع | درج ملفات، بحث داخل المشروع، فهرسة، وتبويبات مرتبطة بالمشروع |
| ثيمات | **28 ثيمًا مدمجًا** (منها Mahdi Kiyani الافتراضي) + ثيمات مخصّصة عبر دائرة الألوان + دعم الثيمات الخارجية |
| ثيمات ديناميكية | Material You على أندرويد 12+، ووضع AMOLED أسود كامل |
| نمط ليلي تلقائي | حسب النظام أو **حسب الوقت** (ليلًا/نهارًا) |
| إضافات | نظام إضافات قابل للتوسّع + تثبيت الحزم من التخزين المحلي |
| بدون إعلانات | لا إعلانات، ولا جمع بيانات، ولا تتبّع |
| مساعد ذكي اختياري | يعمل بمفتاح API الخاص بك فقط، ومُعطّل افتراضيًا |

## البناء من المصدر

### المتطلبات

- JDK 21
- Android SDK مع `compileSdk 37` و`targetSdk 37` (أو أحدث)
- Android NDK + CMake (لبناء وحدات الطرفية الأصلية)
- Git

### الخطوات

```bash
git clone https://github.com/m777m44/Mahdi-editor.git
cd Mahdi-editor

# نسخة تجريبية
./gradlew assembleCommunityDebug

# نسخة الإصدار
./gradlew assembleCommunityRelease
```

الملفات الناتجة:

```
app/build/outputs/apk/community/debug/app-community-debug.apk
app/build/outputs/apk/community/release/app-community-release.apk
```

### التوقيع

- **بناء تجريبي/إصدار دون إعداد:** يتم توقيع نسخة الإصدار تلقائيًا بمفتاح الاختبار المرفق
  (`app/testkey.keystore`) حتى تعمل الحزمة على جهازك مباشرة.
- **بناء للنشر:** أنشئ ملف `signing.properties` في جذر المستودع (انظر
  [`signing.properties.example`](signing.properties.example)) ثم:

```bash
keytool -genkey -v -keystore mahdi-editor.jks -keyalg RSA -keysize 2048 -validity 10000 -alias mahdi
```

تفاصيل كاملة في [docs/BUILDING.md](docs/BUILDING.md).

## نظام الثيمات و«تخصيص الثيم»

يأتي التطبيق بثيم **Mahdi Kiyani** الافتراضي (تركوازي `#14B8A6` + ذهبي `#F5D76E` على أسود تركوازي `#0A1F1F`)،
وإلى جانبه **27 ثيمًا** جاهزًا: الملكي، الزجاجي، المستقبلي، سايبربانك، AMOLED، المحيط، الغابة، الغروب،
الذهبي الوردي، منتصف الليل، دراكولا، نورد، طوكيو الليلية، كاتبوتشينو، غروفبوكس، مونوكاي، سولارايزد،
ون دارك، ماتيريال يو، بغداد، صحراء، دجلة، الفرات، وورقي فاتح، ومهدي الداكن، ومهدي الفاتح، وليل عربي
(المجموع **28**، وتظهر في قائمة الثيمات أيضًا الثيمان الأصليان الموروثان).

كل ثيم يُبنى من **11 لونًا** تُشتق منها بقية خانات Material 3، وله 7 أنماط (صلب/زجاجي/تدرّج/نيون/شبكة/شفق/متحرّك).

من **الإعدادات ‹ الثيمات ‹ تخصيص الثيم** تفتح شاشة التخصيص:

- **دائرة ألوان HSL** مرسومة بـ Compose Canvas (حلقة درجة اللون + مربع تشبّع/سطوع + شريطان).
- قراءة **HEX / RGB / HSL** ونسخ أي منها.
- **معاينة حية** تتغيّر أثناء السحب.
- تعديل الأحد عشر لونًا واحدًا واحدًا.
- **فحص تباين WCAG AA** لكل لون أمام الخلفية.
- **توليد باليت** متكامل/ثلاثي/متجاور من اللون الأساسي.
- **حفظ** الثيم داخل التطبيق، و**تصدير/استيراد JSON**.

## تجهيز المكتبات تلقائيًا

قبل أن يُشغَّل أي سكربت بـ**تشغيل**، يقرأ المشغّل السكربت ويتعرّف على مكتباته ثم يثبّت الناقص فقط بآخر إصدار:

- **بايثون:** يحلّل شجرة `import` / `from` (AST) ويستبعد المكتبة القياسية والملفات المحلية،
  ويحوّل الأسماء الشائعة تلقائيًا (`PIL`→pillow، `cv2`→opencv-python، `sklearn`→scikit-learn، `bs4`→beautifulsoup4…).
- **JavaScript/TypeScript:** يقرأ `require` و`import` ويستبعد الوحدات المدمجة والمسارات النسبية.
- **PHP:** يشغّل `composer install` تلقائيًا عند وجود `composer.json`.
- يلتقط أوامر `pip install …` المكتوبة **داخل** السكربت (نصًّا أو على شكل قائمة في `subprocess`) ويجهّزها مسبقًا،
  ويصلح الأخطاء الشائعة مثل `pip install request` → `requests`.
- يثبّت على دفعات متوازية (أسرع)، ويعيد المحاولة، ويضيف أدوات البناء تلقائيًا إذا احتاجت مكتبة ترجمة.
- `pip` و`pip3` و`python` تصبح متاحة دائمًا، ويتجاوز `PEP 668` الذي كان يُفشل `pip install` في Ubuntu الحديثة.

للتحكم: `MAHDI_AUTO_DEPS=0` للتعطيل، و`MAHDI_PIP_INDEX` / `MAHDI_NPM_REGISTRY` لاستخدام مرآة أسرع.

### تنزيل أسرع
```bash
mahdi_dl https://example.com/big-archive.tar.gz
```
ينزّل الملف بعدة اتصالات متوازية (aria2c)، مع استئناف تلقائي وإعادة محاولة عبر curl/wget.

## اللغات والتشغيل

- **47 لغة** للتلوين النحوي بقواعد TextMate مضمّنة (Python، JavaScript، TypeScript، PHP، C، C++، C#،
  Java، Kotlin، Swift، Go، Rust، Ruby، Lua، R، SCSS، SQL، Shell، Markdown، YAML، XML…).
- **26 لغة قابلة للتشغيل** مباشرة: Python، Node/TypeScript، PHP، C/C++، C#، Java، Kotlin، Rust، Ruby،
  Lua، R، Go، Julia، Groovy، Scala، OCaml، Elixir، Erlang، Haskell، Perl، Shell، SQL، AWK، Pascal،
  Tcl، Fortran.
- التشغيل يتم داخل **طرفية Ubuntu** المدمجة عبر PRoot: يُثبَّت المفسّر تلقائيًا عند أول استخدام،
  والمخرجات تظهر مباشرة في الطرفية مع إمكانية الإيقاف بـ `Ctrl+C`.
- **الإعدادات ‹ التطبيق ‹ اللغات المدعومة** تعرض القائمة الكاملة والفروق بين التلوين والتشغيل.

## الترميزات

- **23 ترميزًا** بأسماء عربية: UTF-8/16/32 (LE وBE)، ASCII، ISO-8859-1، **ISO-8859-6**،
  **Windows-1256**، Windows-1251/1252، KOI8-R، GBK، GB18030، Big5، Shift-JIS، EUC-JP، EUC-KR،
  TIS-620، VISCII، MacRoman، IBM437، وبقية ترميزات المنصّة.
- **كشف تلقائي** عند فتح أي ملف: بصمة BOM ← صلاحية UTF-8 ← تخمين الترميز العربي ← Latin-1.
  يمكن إيقافه من **الإعدادات ‹ المحرر ‹ الترميز الافتراضي**.

## دعم اللغتين العربية والإنجليزية

يُشحن التطبيق بترجمة كاملة للعربية (الافتراضية) والإنجليزية:

- كل النصوص في `values/` و`values-ar/` بالعربية، ونظيرها الكامل في `values-en/` بالإنجليزية
  (بما فيها نصوص 2.0 و2.1 و2.2 ورسائل المشغّل وخوادم اللغة).
- **الإعدادات ‹ التطبيق ‹ اللغة** تبدّل بين «العربية (ar)» و«English (en)» فورًا.
- الاتجاه يتبع اللغة تلقائيًا: RTL للعربية وLTR للإنجليزية (`supportsRtl`).
- أسماء اللغات البرمجية وأسماء الترميزات تتبع لغة التطبيق أيضًا.

## اللغة والاتجاه

- التطبيق **عربي بالكامل**: مجلد الموارد الافتراضي `values/` عربي، والمجلد `values-ar/` نسخة مطابقة،
  ولا توجد أي ترجمة أخرى في التطبيق. يظهر بالعربية على أي جهاز مهما كانت لغة نظامه.
- اللغة الافتراضية `ar` وتُطبّق قبل بناء الواجهة، وشاشة **الإعدادات ‹ اللغة** تعرض العربية وحدها.
- تُضبط اتجاهات الواجهة تلقائيًا (RTL)، مع مراعاة الأيقونات والدرج وشريط الأدوات.
- الملفات النصية تبقى باتجاه LTR داخل المحرر — الاتجاه العربي يخصّ واجهة التطبيق فقط.
