# Mahdi-Editor

<div align="center">

**محرر نصوص وأكواد متقدم لنظام أندرويد — بالعربية بالكامل 🇮🇶**

</div>

Mahdi-Editor محرر أكواد مفتوح المصدر لنظام أندرويد، مبني على محرّك تحرير احترافي، بواجهة عربية كاملة
ودعم أصيل للاتجاه من اليمين إلى اليسار. يوفّر تلوين الأكواد، وخوادم لغة LSP، وطرفية Linux مدمجة،
ومدير مشاريع، ومتجر إضافات وثيمات — كل ذلك **دون إعلانات ودون تتبّع ودون حسابات**.

## المزايا

| الميزة | الوصف |
|---|---|
| واجهة عربية 100% | جميع النصوص والقوائم والرسائل معرّبة، ولا تعتمد أي شاشة على نصّ إنجليزي |
| دعم RTL كامل | الواجهة تنقلب تلقائيًا عند اختيار العربية، و**الأرقام تُعزل بـLRI/PDI** فلا تنقلب `100` إلى `001` |
| تلوين الأكواد | 50 قاعدة TextMate مضمّنة، وتلوين تلقائي حسب الامتداد |
| خوادم لغة LSP | إكمال الشيفرة، تشخيص الأخطاء، التنسيق، الانتقال إلى التعريف والمراجع، وإعادة تسمية الرموز — وتشمل HTML وCSS وJSON وTypeScript وMarkdown وESLint وPython (Pyright) وBash وXML وEmmet |
| طرفية مدمجة | Ubuntu عبر PRoot مع مشغّلات سكربتات ومدير حزم |
| مدير مشاريع | درج ملفات، بحث داخل المشروع، فهرسة، وتبويبات مرتبطة بالمشروع |
| ثيمات | 4 ثيمات أساسية + **40 ثيمًا مميزًا مزدوج الوضع** (فاتح + داكن) في المتجر |
| نمط ليلي تلقائي | حسب النظام أو **حسب الوقت** (ليلًا/نهارًا) + وضع AMOLED أسود كامل |
| مركز اللغات | **٤ تبويبات**: لغة الواجهة · لغات البرمجة · المشغلات · خوادم اللغة — مكان واحد لكل ما يخصّ اللغة |
| اقتراحات أثناء الكتابة | شريط أسفل المحرّر: كلمات الملف + الدوال المدمجة + كلمات اللغة، بلا إنترنت وقابل للتعطيل |
| عدسة التحديد | عدسة 1.5× تتبع الإصبع عند سحب مقابض التحديد، مع سحب التحديد بعد الضغط المطوّل |
| أيقونة التطبيق | **١١ أيقونة كرتونية ثلاثية الأبعاد** بحرف M (روبوت مبرمج — الافتراضية · الحرف M المجسّم · ثعلب · قط · باندا · تنين · بومة · بطريق · أرنب · همستر · أكسولوتل) تتبدّل فورًا عبر activity-alias بمعاينة حقيقية |
| مساحة التخزين | شاشة تُفصّل أين تذهب البيانات (صورة أوبنتو · أدوات · مخازن · كاش) وتنظّفها بأمان |
| متصفح المعاينة | معاينة HTML داخل التطبيق بشريط عنوان وتنقّل وتقدّم، دون مغادرة المحرّر |
| تحديث داخلي | فحص إصدارات GitHub داخل التطبيق، تنزيل بشريط تقدّم، وتثبيت مباشر بلا متصفح |
| أيقونات ديناميكية | إحدى عشرة أيقونة كرتونية بحرف M تتغيّر معها أيقونة الشاشة الرئيسية **وشعار الشاشة الرئيسية داخل التطبيق وشاشة البداية** |
| الدليل المدمج | توثيق كامل بلا إنترنت: المحرّر، الطرفية، Git، الثيمات، الحزم، الخوادم |
| مخزون اللغات | تثبيت المفسّرات داخل التطبيق بحالة **حقيقية** من القرص ونسبة تقدّم وشارة «مثبت» تبقى بعد إعادة التشغيل |
| استئناف العمل | آخر ملف مفتوح + موضع المؤشّر والتمرير + التبويبات، بحفظ مؤجَّل 500ms |
| بدون إعلانات | لا إعلانات، ولا جمع بيانات، ولا تتبّع |

## البناء من المصدر

### المتطلبات

- JDK 21
- Android SDK مع `compileSdk 37` و`targetSdk 37` (أو أحدث)
- Android NDK + CMake (لبناء وحدات الطرفية الأصلية)
- Git

### الخطوات

```bash
git clone https://github.com/m777m44/Mahdi-editor.git
cd Mahdi-editor

# نسخة تجريبية
./gradlew assembleCommunityDebug

# نسخة الإصدار
./gradlew assembleCommunityRelease
```

الملفات الناتجة:

```
app/build/outputs/apk/community/debug/app-community-debug.apk
app/build/outputs/apk/community/release/app-community-release.apk
```

### التوقيع

- **بناء تجريبي/إصدار دون إعداد:** يتم توقيع نسخة الإصدار تلقائيًا بمفتاح الاختبار المرفق
  (`app/testkey.keystore`) حتى تعمل الحزمة على جهازك مباشرة.
- **بناء للنشر:** أنشئ ملف `signing.properties` في جذر المستودع (انظر
  [`signing.properties.example`](signing.properties.example)) ثم:

```bash
keytool -genkey -v -keystore mahdi-editor.jks -keyalg RSA -keysize 2048 -validity 10000 -alias mahdi
```

تفاصيل كاملة في [docs/BUILDING.md](docs/BUILDING.md).

## مركز اللغات والمشغلات

**الإعدادات ‹ اللغات** — شاشة واحدة بأربعة تبويبات، ولا مكان ثانٍ لأي إعداد لغة:

| التبويب | ماذا فيه |
|---|---|
| **لغة الواجهة** | العربية/الإنجليزية، مع علامة ✓ على المختار |
| **لغات البرمجة** | المضمّنة · المثبّتة بواسطتك (✖️ لحذفها) · المتاحة للتثبيت (٤٨ لغة) |
| **المشغلات** | إصدار كل مفسّر + مساره + **تثبيت** بنسبة حقيقية + **حذف** فعلي (apt purge) في الخلفية بلا فتح الطرفية، وإذا كانت الحزمة أساسية في أوبنتو تظهر «مضمّن» بدل «مثبَّت» فلا يبقى زرّ حذف لا يعمل |
| **خوادم اللغة** | كل خوادم LSP المدمجة: تثبيت/إزالة، تشغيل/إيقاف، وخادم خارجي يُضاف بحزمة |

الثيمات وحزم الأيقونات لها مداخلها الخاصة: **الإعدادات ‹ الثيمات**، وتفاصيل أي حزمة
مثبّتة تُفتح من المحرّر نفسه.

### متصفح المعاينة والدليل

- **متصفح المعاينة**: صفحات HTML التي يشغّلها زرّ التشغيل تُعرض داخل التطبيق في شاشة
  كاملة — شريط عنوان قابل للتعديل، رجوع/تقدّم، إعادة تحميل، شريط تقدّم، **زرّ الرئيسية**
  للعودة مباشرة إلى شاشة البداية، وزرّ فتح خارجي.
- **الدليل**: **الإعدادات ‹ دليل Mahdi-Editor** يعرض التوثيق الكامل بلا إنترنت بالعربية أو
  الإنجليزية: البدء، المحرّر، الطرفية، Git، الثيمات، الاستوديو، صيغ الحزم، الخوادم، اللغات،
  الترميزات، والخصوصية.

### صيغ الحزم المقبولة

يقبل التطبيق من مدير الملفات: **`.mahdi`** و**`.xed`** و**`.xedx`** — لأن الجميع يستخدم البنية
نفسها: `manifest.json` + `theme.json` أو `icons` أو ملف APK.

## اللغات والتشغيل

- **48 لغة** مسجّلة في المحرّر، و**كلها قابلة للتشغيل المباشر** — لا لغة «تحرير فقط».
- **50 قاعدة TextMate** مضمّنة للتلوين النحوي (Python، JavaScript، TypeScript، PHP، C، C++، C#،
  Java، Kotlin، Swift، Go، Rust، Ruby، Lua، R، SCSS، SQL، Shell، Markdown، YAML، XML…).
- التشغيل يتم داخل **طرفية Ubuntu** المدمجة عبر PRoot: يُثبَّت المفسّر عند الحاجة، والمخرجات تظهر
  مباشرة في الطرفية مع إمكانية الإيقاف بـ `Ctrl+C`.
- محرّك التشغيل يستمدّ امتداداته **مباشرة من سجلّ اللغات**، فأي لغة تُضاف تصبح قابلة للتنفيذ تلقائيًا.
- **كل ما يخصّ اللغة في مكان واحد** (4.2.0): **الإعدادات ‹ اللغات** — تبويب واحد يجمع
  **لغة الواجهة** (العربية/الإنجليزية) و**لغات البرمجة**: **مثبتة مسبقًا** (Python، PHP، HTML —
  غير قابلة للحذف) · **مثبتة** (✖️ ← تأكيد ← حذف كامل مع حذف الحزم) · **متاحة** (تثبيت بحالة
  حقيقية من القرص، مهلة 120 ثانية، وتراجع عند الفشل) — مع إحصاء المثبَّت من الإجمالي.
- الخط الافتراضي للمحرّر والطرفية **JetBrains Mono** مضمَّن داخل التطبيق (بلا تنزيل)،
  مع تباعد حروف صفري وهامش يمين يمنعان قصّ آخر حرف في الكلمات الطويلة.

### محرّك تشغيل لا يرفض شيئًا (4.1.0)

- **سطر shebang يحكم أولًا**: أي سكربت يبدأ بـ `#!/usr/bin/env python3` أو `#!/bin/bash` أو
  `#!/usr/bin/php` يُشغَّل بمفسّره الصحيح **مهما كان امتداده أو حتى بلا امتداد** — كما تفعل
  طرفية لينكس بالضبط.
- **تعرّف تلقائي على المحتوى** حين يغيب الامتداد وshebang: `<?php` ← PHP، `package main` ← Go،
  `console.log` ← Node، `import/def/print(` ← Python، وإلا bash.
- **ملفات تنفيذية جاهزة**: أي ملف ELF يُشغَّل مباشرة، وكذلك `.pyz` و`.zipapp` و`.jar` و`.cgi`.
- **بيئة UTF-8 موحّدة** لكل المفسّرات (`LANG`/`LC_ALL`/`PYTHONIOENCODING`/`PYTHONUTF8`)، فلا
  يفشل سكربت بسبب نص عربي أو إيموجي في مخرجاته — نفس سلوك Termux على الجهاز.

### تشغيل من أي مكان في الهاتف (4.2.0)

- **لا يقتصر على Download أو الطرفية**: أي ملف داخل ذاكرة الهاتف — `Documents`، `Pictures`،
  `Android/media`، بطاقة SD، أو أي مجلد — يعمل مباشرة بزرّ التشغيل.
- **بإذن «كل الملفات»** (`Environment.isExternalStorageManager()`) يُشغَّل الملف **في مكانه**
  نفسه، فيرى السكربت جيرانه وملفّاته المرافقة.
- **بلا الإذن** تُنسخ نسخة مؤقّتة إلى `/home/mahdi-run/<اسم-منقّى>` داخل الطرفية وتُشغَّل هناك
  (`workingDir` هو نفسه)، فتعمل السكربتات التي تحتاج بيئة طرفية كاملة.
- **`content://`** (من مدير ملفات آخر أو من «مشاركة») يُقرأ ويُنسخ بنفس الطريقة — لا رسالة
  «نوع ملف غير مدعوم» بعد الآن.
- نُقطتا وصل `/mnt` و`/media` مربوطتان داخل الطرفية مع `/run` و`/etc/hosts`، فتظهر بطاقة SD
  والوسائط من داخل Ubuntu.

### اختصارات التشغيل (3.1.0)

بدل `python3 script.py` اكتب `py script.py` — وتعمل بأي حالة أحرف: **`py` · `Py` · `pY` · `PY`**.

```bash
py script.py     # بايثون
js app.js        # جافاسكربت (Js · jS · JS)
ts app.ts        # TypeScript (Ts · tS · TS)
run file.any     # أي امتداد مدعوم — يكتشف المفسّر تلقائيًا
usage            # بطاقة مختصرة بالأمثلة
```

- الاختصارات **ملفّات تنفيذية** داخل `$LOCAL/bin` (على `PATH`)، فتعمل في bash وsh والسكربتات والطرفيات الفرعية.
- `py --help` و`js --help` و`run --help` تعرض شرحًا موجزًا لكل اختصار.
- الحالة والنسخ تُقرأ من القرص: JavaScript وTypeScript تحتاجان **Node**، وJava/Kotlin تحتاجان **JDK**،
  وC/C++ تحتاجان **GCC** — وتُثبَّت هذه من شاشة «بيئات التشغيل» بنسبة تقدّم حقيقية.

## الترميزات

- **23 ترميزًا** بأسماء عربية: UTF-8/16/32 (LE وBE)، ASCII، ISO-8859-1، **ISO-8859-6**،
  **Windows-1256**، Windows-1251/1252، KOI8-R، GBK، GB18030، Big5، Shift-JIS، EUC-JP، EUC-KR،
  TIS-620، VISCII، MacRoman، IBM437.
- **كشف تلقائي** عند فتح أي ملف: بصمة BOM ← UTF-16 بلا بصمة ← صلاحية UTF-8 ← تخمين الترميز
  العربي ← Latin-1. يمكن إيقافه من **الإعدادات ‹ المحرر ‹ الترميز الافتراضي**.
- **زرّ «الترميز» في شريط المحرّر** (4.1.0): يعيد فتح الملف بأي ترميز آخر ويجعله ترميز الحفظ لهذا
  الملف وحده — فالملف القديم بترميز Windows-1256 يُعرض صحيحًا بلمسة، دون تغيير الإعداد العام.
- **حفظ بلا فقدان**: إن حوى النص أحرفًا لا يمثّلها الترميز المختار (مثل حرف عربي في ملف ASCII)
  يُحوَّل الملف تلقائيًا إلى UTF-8 مع رسالة واضحة — بدل كتابة `?` مكان الحرف بصمت.

### الملفات للقراءة فقط (`Media is read-only`)

- أندرويد 11+ يمنح التطبيق **قراءة فقط** لمستندات كثيرة (مستند من تطبيق آخر، أو داخل
  `/Android/data`)، فكان الحفظ يفشل برسالة استثناء خام.
- الآن: عند أول حفظ يفشل يُفتح **«حفظ باسم»** فورًا مع اسم الملف نفسه، ويُحوَّل التبويب للملف
  الجديد — فلا يُفقد أي نص، ولا تظهر رسالة `Media is read-only` بعد اليوم.

## اللغة والاتجاه

- التطبيق **عربي بالكامل**: مجلد الموارد الافتراضي `values/` عربي، والمجلد `values-ar/` نسخة مطابقة،
  ويظهر بالعربية على أي جهاز مهما كانت لغة نظامه.
- نسخة إنجليزية كاملة متاحة أيضًا من **الإعدادات ‹ التطبيق ‹ اللغة** (`ar` / `en`)،
  والاتجاه يتبع اللغة تلقائيًا: RTL للعربية وLTR للإنجليزية.
- الملفات النصية تبقى باتجاه LTR داخل المحرر — الاتجاه العربي يخصّ واجهة التطبيق فقط.

---

## تجهيز المكتبات تلقائيًا

قبل أن يُشغَّل أي سكربت بـ**تشغيل**، يقرأ المشغّل السكربت ويتعرّف على مكتباته ثم يثبّت الناقص فقط:

- **بايثون:** يحلّل شجرة `import` / `from` (AST) ويستبعد المكتبة القياسية والملفات المحلية،
  ويحوّل الأسماء الشائعة تلقائيًا (`PIL`→pillow، `cv2`→opencv-python، `sklearn`→scikit-learn،
  `bs4`→beautifulsoup4…).
- **JavaScript/TypeScript:** يقرأ `require` و`import` ويستبعد الوحدات المدمجة والمسارات النسبية.
- **PHP:** يشغّل `composer install` تلقائيًا عند وجود `composer.json`.
- يلتقط أوامر `pip install …` المكتوبة داخل السكربت ويجهّزها مسبقًا، ويصلح الأخطاء الشائعة
  مثل `pip install request` → `requests`.
- يثبّت على دفعات متوازية، ويعيد المحاولة، ويضيف أدوات البناء تلقائيًا إذا احتاجت مكتبة ترجمة.
- `pip` و`pip3` و`python` متاحة دائمًا، ويتجاوز `PEP 668` الذي كان يُفشل `pip install` في Ubuntu الحديثة.
- **صمت تام:** إذا كانت كل المكتبات موجودة لا يُطبع أي سطر — لا «INFO كل المكتبات موجودة مسبقًا» ولا غيرها.

للتحكم: `MAHDI_AUTO_DEPS=0` للتعطيل، و`MAHDI_PIP_INDEX` / `MAHDI_NPM_REGISTRY` لاستخدام مرآة أسرع.

### تنزيل أسرع

```bash
mahdi_dl https://example.com/big-archive.tar.gz
```

ينزّل الملف بعدة اتصالات متوازية (`aria2c`)، مع استئناف تلقائي وإعادة محاولة عبر curl/wget.

## الطرفية وبطاقة التقدّم

- زرّ **▶️** يشغّل السكربت مباشرة بلا أي نافذة موافقة؛ وملفات `/sdcard` تُنسخ إلى `~/mahdi-run` تلقائيًا.
- **شريط أدوات سريع** فوق لوحة المفاتيح: `Ctrl+C` · `Ctrl+D` · مسح · `Tab` · `Esc` · الأسهم الأربعة ·
  لصق من الحافظة · تكبير/تصغير الخط.
- عند تثبيت مكتبة تظهر **كبسولة تقدّم واحدة** داخل الطرفية (٢١٢dp في طرفها السفلي): اسم
  المكتبة والنسبة والشريط — ولا تحجب نصًّا ولا شريط المفاتيح.
- **النسبة لا تجمد أبدًا:** مراحل بأوزان (حلّ الإصدارات ٤‑١٢ · تنزيل بالبايتات ١٢‑٨٢ ·
  بناء وتثبيت ٨٢‑٩٩) ونبضة تحرّك الرقم كل ٠٫٤ ثانية إذا صمتت المرحلة، بسقف «آخر نسبة حقيقية
  + ١٥» فلا يكذب الرقم ولا يرتدّ. وبعد ستّ ثوانٍ بلا بايت جديد تتحوّل البطاقة إلى
  «شبكة بطيئة…» بدل أن تبدو ميّتة.
- **لا نصوص تتراكب:** لا سطر `INFO` مختلط، وشريط الطرفية (`MAHDI_BAR=1`) مطفأ افتراضيًا حتى
  تبقى نسبة واحدة فقط على الشاشة.
- **لا ضجيج ولا Traceback:** فشل التثبيت يظهر كسطر عربي واحد («لم تعمل الحزمة … — مكتبة بايثون
  غير مثبّتة») ومعه مكان التثبيت، بدل عشرات أسطر `WARNING: Retrying` وأثر بايثون الكامل.
- **DNS محدَّث في كل جلسة:** خوادم الاسم تُقرأ من النظام وتُكتب في `resolv.conf` قبل فتح الطرفية،
  فلا تفشل pip بـ`Temporary failure in name resolution` بعد تغيّر الشبكة.
- **الخط الافتراضي 12**، والتكبير بإصبعين **متدرّج بلا قفزات**: حجم مرجعي عند بداية الإيماءة
  وتراكم نسبي وتنعيم بخطوة 0.5sp داخل مدى 8–32، والحجم يُحفظ ويبقى بعد إعادة التشغيل.
- **شعار MAHDI** المرسوم بـASCII يظهر عند فتح الطرفية **وعند بداية كل تشغيل سكربت** —
  داخليًا كان الملف أو خارجيًا، تفاعليًا أو عبر `bash -lc`. الشكل وحده بلا أي أسطر شرح
  تحته، ورقم الإصدار فيه يُقرأ من التطبيق نفسه فلا يتخلّف. يمكن تعطيله بـ`MAHDI_BANNER=0`.
- الطرفية تعرض العربية **متّصلة الحروف وبالاتجاه الصحيح** بفضل محرّك BiDi المدمج،
  و**الأرقام LTR دائمًا**: `100` تبقى `100` ولا تصير `001` في أي سطر عربي.

## مخزن المكتبات الداخلي

- كل حزمة تُنزَّل (بايثون أو Node) تُحفظ داخل التطبيق في `~/.mahdi/cache` (‏`wheels` و`pip` و`npm`).
- المكتبة المحفوظة تُثبَّت فورًا من المخزن **بلا إنترنت**، وتظهر البطاقة «مثبّتة مسبقًا — من المخزن».
- قبل أي تثبيت يُفحص سجلّ الحزم، فلا يُثبَّت إلا **الناقص فعلًا** — لا إعادة تثبيت ولا تنزيل مكرّر.
- لحذف المخزن وتوفير المساحة: `rm -rf ~/.mahdi/cache`.
